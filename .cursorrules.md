# Proxyma - Agent Context & Reference Guide

Condensed context for AI agents: architecture, SSOT helpers, what not to reinvent, and coding rules.

---

## Project Goal

**Proxyma** is a distributed, heterogeneous P2P resource and compute orchestrator (Go). It unifies devices (servers, desktops, mobiles) into one mesh that shares compute, storage, and related capabilities over mTLS (with QUIC hole-punch and HTTP relay fallback).

## Design Rules (Always On)

* **Golden rule (duplication)**: If changing one behavior requires touching **>2 code zones**, compress into a shared helper (see semantic-compression skill). Do **not** copy service CRUD, peer fan-out, relay forward, blob fetch/stage, or unix dial stacks.
* **Continuous granularity (3 tiers)**: L3 wrappers must not hide L1/L2. Example: `dispatchUnixOrLocal` / `dispatchUnixLocalOrOffline` (L3) use `sendUnixSocketCommand` which uses `DialUnix` / `WriteUnixRequest` / `ReadUnixResponse` (L1). Streaming uses `ScanUnixNDJSON` — never fork a full dial path.
* **Slice boundary guards** when trimming slices.
* **Domain enums in `protocol`**: `ServiceType`, `IsStreaming()`, `Normalize()` all read `serviceTypeSpecs` (`protocol/service_types.go`). No ad-hoc type string switches anywhere — a new type is 1 row there + 1 row in `compute.serviceTypeBuilders`.
* **Tables over switches**: a discriminant that already has an SSOT table must not grow a parallel `switch` — gossip kind (`server.catalogKinds`), HTTP route + auth policy (`server.httpRoutes`), service type (above).
* **Node addresses**: `protocol.SchemeAddr` (L1) / `HTTPSAddr` / `HTTPSAddrPort` (IPv6-safe). Never concatenate `scheme://host:port`. Peer virtual hosts: **`PeerLocalDomain` / `PeerLocalHost` / `ParsePeerLocalHost` / `PeerHTTPURL` / `PeerHTTPSURL`** — never hardcode `.proxyma.local`.
* **Service query**: `protocol.QueryService` + `WithServiceQuery(path, name)` — never hand-roll `?service=` / `?` vs `&`.
* **HTTP ack envelopes**: `protocol.APIMessage` / `APIStatus` / `APITaskAck`; write via `utils.RespondMessage` / `RespondStatus` (or `RespondJSON` with the typed struct). Do not invent `map[string]string{"message":...}`.
* **Leave/Offline body**: `protocol.PeerIDRequest` on `PeerClient.Leave` / `Offline` (same as HTTP handlers).
* **AddPeer body**: `protocol.AddPeerRequest` on `PeerClient.AddPeer` (same as Announce/HTTP; never `*bytes.Buffer`).
* **Missing mTLS**: `p2p.ForbidMissingMTLS` / `RequirePeerCN` (server keeps thin wrappers) — do not retype `"mTLS certificate required"`.
* **Error wording**: user-facing validation text lives in `protocol/errors.go` (`ParamTypeError`, `ParamOptionError`, `MissingParamError`, `ErrEmptyPipelineID`). Validators may stay per-layer; the message must not be retyped.
* **No parallel maps on one key**: per-peer/per-entity state goes in one struct under one lock (`peerState`), not N maps with N mutexes.
* **No `panic` / `os.Exit` outside `main` and `Execute`**: CLI commands use `RunE`; libraries return errors — `storage.NewStorageEngine` and `server.New` both return `(T, error)`. Bolt/disk failures propagate instead of collapsing into a bool.
* **Long-lived goroutines re-check their lifetime after any blocking network call**, before logging or invoking callbacks (`QUICManager.lifetime`, `NATMapper.stopped`). A leaked goroutine that logs after its owner is gone panics the test binary.
* **Never mutate a `tls.Config` that is already in use**: `crypto/tls` reads it concurrently during handshakes. Swap immutable snapshots behind `GetConfigForClient` / `GetClientCertificate`.
* **UI hints**: `protocol.InferUIHint` / `EffectiveUIHint` write/fill at schema time; bind passes through; Android **never** re-sniffs param names.
* **Bind errors**: `BindErrorJSON` / `BindMessageJSON` / `ParseBindError` / `IsBindError` — JSON `{"error":...}` only (no `"error:"` prefix; never double-wrap).
* **In-memory registry**: Persist `services.json` only on mutation (`compute.UpsertLocalService` / `DeleteLocalService`); runtime resolves via `Compute.GetService` / `GetHandler`.
* **JSON contracts**: One SSOT — e.g. `protocol.BandwidthStats` tags (`upload_speed`, …). CLI must not redefine parallel structs with different tags.
* **No unrequested commits**.

## Remediation Contracts (Current)

* **Server lifetime**: `Ready`/`IsReady` mean both Unix and TCP listeners are bound. Server-owned goroutines and in-process calls join the shutdown barrier through `goOwned` / `AcquireWorkLease`; HTTP and Unix work is tracked too. Shutdown stops admission, cancels `lifetimeCtx`, closes listeners/connections, joins NAT/listener/work/download/compute/router/QUIC/storage owners, and only then closes `ShutdownDone`.
* **Compute lifetime**: construct with `compute.NewComputeEngine(parentCtx, ...)`. Its private `lifetimeCtx` / `cancelLifetime` own workers and derived RPC/handler timeouts; parent cancellation closes the engine. Request contexts still travel as method arguments—never store a request context on `ComputeEngine`.
* **NAT / QUIC / router**: access published NAT state through `CurrentNATState` / `natMu`; schedule and join setup with `beginNATWork` / `stopNATWork`. `NATMapper.Start` / `WaitReady` / `Stop` is one synchronized lifetime. Router prewarms are cancellation- and generation-bound; route removal blocks late QUIC sessions, and `PeerClient.Close` joins router work.
* **Relay**: queue capacity and `RelayManager.workSlots` bound pending and active work. Decode through `decodeRelayJSON`; enforce `MaxRelayBodyBytes` on requests and the capped response writer. Poll/request work must remain server-owned and lifetime-cancelable.
* **Durable mutation ordering**: outbox v2 uses separate entry/generation/reservation buckets. `notifyWithOutbox` stages a generation before send and compare-deletes only the acknowledged bytes; `prepareOutboxMutation` stages gossip before VFS/pipeline commit and reconciles on commit/rollback. Legacy migration moves only structurally recognized metadata. Download work (`download_intents`) and orphan cleanup (`pending_blob_gc`) are durable intents reconciled after restart.
* **Storage integrity / manifests**: server paths use error-preserving APIs (`GetFileMetaE`, `IsSubscribedE`, `HasServiceSubscriptionsE`, `IsServiceSubscribedE`, `ProcessRemoteManifestE`). Manifest reconciliation processes every entry in deterministic name order, preserves successful decisions, aggregates per-entry errors, and `ProcessRemoteManifestFromSource` still stages durable intents for every successful missing entry. VFS ordering is total: version, tombstone, hash, size, name. Blob writes stage/verify outside the metadata lock, then commit; remote content is accepted only when SHA-256 and the current name/version/hash/live tuple match.
* **`services.json`**: use compute Load/Save/Upsert/Delete helpers only. They combine a canonical-path in-process RW lock, Linux/Android advisory `flock`, and atomic `utils.WriteJSONFile` (temp + fsync + rename + parent fsync).
* **Pipelines / tasks**: `PipelineSchema.Version`, `Deleted`, `PipelineSchemaHash`, `ValidatePipelineRevision`, and `ApplyPipelineRevision` define revision/tombstone integrity. `PipelineExecutionState` is engine-owned and binds ID/version/hash/current step/outputs/producers plus pinned `selected_targets`; continuations require `CapabilityPipelineState` **v2**. Authenticated producer/delegate checks guard callbacks. Task status transitions are `pending` → `ingesting` when output import is required → `completed`, or `failed`; terminal states do not regress and retention is bounded.
* **Streams**: HTTP peers and Unix clients explicitly negotiate legacy or v1 framing. Legacy carries raw object chunks and ends successfully at EOF; v1 uses `ServiceStreamFrame` / versioned `UnixResponse` chunk/error/complete frames and requires a terminal frame. Never guess control records or accept mixed legacy/v1 framing. Cancellation propagates from bind `CancelStream` through contexts, and every NDJSON path uses `utils.MaxNDJSONFrameBytes`.
* **Bind runtime**: the singleton node runtime is guarded by `srvMutex`; `StartNode` publishes it only after `Server.Ready`, `IsNodeRunning` requires readiness, and `StopNodeWithError` waits for finalization while leaving timed-out state marked stopping. Join installation is a journaled stage/backup/swap transaction recovered before start. Capture one `canonicalStoragePath` per operation, and normalize Unix unavailability separately from daemon/application errors so offline fallback cannot mask a live daemon failure.
* **gomobile / Android**: keep exported gomobile signatures stable. `make test-android-contract` uses the host-only `androidcontract` tag to select Android WebRTC stubs: registration fails immediately and signaling returns the exact JSON HTTP 501 unsupported contract. Hermetic `make test-android` depends on it, builds one temporary fresh AAR, verifies Java descriptors including the UISchema JSON bridge, isolates Android user state, and passes that exact AAR to Kotlin unit tests, lint, and assemble; the dedicated CI Android job provisions pinned Go/Java/SDK/NDK/Gradle inputs and runs this target. Pion helpers exist only on `!android && !androidcontract`. Compose work belongs to `ViewModel`/`viewModelScope`, cancellable streams own a `StreamLease`, `ProxymaService` owns daemon start/stop, and UI binding state must unbind on Activity destruction.
* **Accepted trust/network limits**: enrolled mTLS peers and explicitly selected pipeline delegates are trusted; capability/provenance fields are authorization metadata, not cryptographic proofs. Mixed-version distributed pipeline continuations are rejected unless the peer supports pipeline-state v2. There is no TURN fallback, and UPnP/NAT-PMP mapping is IPv4-only.
* **Race gate**: H1 (live TLS mutation) and H2 (NAT-after-shutdown) are closed. A full `go test -race ./...` / `make test-race` is required; do not preserve a “known race failure” exemption.

## Repository Map (Current)

### CLI — `cmd/proxyma/`
* `root.go` — Cobra from **`cliRegistry()`** (`VisibleRegistry("cli")` + Hidden CLI escapes) + `Execute`.
* `cli_actions.go` — `executeActionLocal` → **`NormalizeActionArgs`** → **`ValidateActionArgs`** → `cliEscapes` OR **`InvokeDomainActionPrepared`** (open/join/run/clone/edit escapes). Hidden join/edit_pipeline stay on Cobra via `cliRegistry`.
* Byte/rate rendering: call `uischema.FormatBytes` / `FormatRate` directly (the local wrapper file is gone).
* `cli_open.go` — editor launch, stream listener, system open.
* `service_help.go` — schema help; `ParseInputsToJSON` → `uischema.NormalizePayloadJSON`; offline schema via `GetServiceSchema` offline arm.
* Table render: `uischema.ProjectRows` in `root.go`.
* `cli_daemon_test.go::TestCLIContractLiveDaemon` builds the real CLI and drives a real bind daemon over Unix IPC for upload help/default+explicit names, list, telemetry, and clean shutdown.

### Bindings — `cmd/proxyma-bind/` (gomobile + CLI bridge)
* **IPC L1**: `DialUnix`, `WriteUnixRequest`, `ReadUnixResponse`, `ScanUnixNDJSON` in `bind.go`.
* **IPC L2/L3**: `sendUnixSocketCommand`, **`InvokeDomainAction`** (L3 Normalize→Validate) / **`InvokeDomainActionPrepared`** (L2) / `NormalizeActionArgs` / **`ValidateActionArgs`** / **`uischema.NormalizePayloadJSON`**, `dispatchUnixOrLocal`, `dispatchUnixLocalOrOffline` + **`offlineHooks`** map (add/remove/detail). CLI prep once then Prepared; wrappers/JNI use L3.
* Execution: **`server.CallUnixUnary`** — single body shared with unix listener.
* `BindErrorJSON` / `BindMessageJSON` / `ParseBindError` / `IsBindError` — error envelope SSOT.
* Socket path: **`protocol.UnixSockPath`** (never hardcode `proxyma.sock`).
* `ParameterDetail` = `uischema.ParameterDetail`.
* `GetServiceSchema` / `GetServiceDetails`; `RunPipeline` → `RunService` alias.
* Do **not** reimplement offline `services.json` RMW by hand.

### Server — `internal/server/`
* `server.go` — lifecycle (`Ready`, `goOwned`, `AcquireWorkLease`, `ShutdownDone`), bandwidth wrappers.
* `peers.go` — topology (`AddPeer`/`AnnouncePresence`/`RemovePeer`/`SetPeer*`/`CheckNAT`); `Server.AddPeer` applies registry `evicted` to Storage + routes.
* `registry.go` — **`PeerRegistry`**: one `map[string]*peerState` under one `RWMutex`. **`hasRecord`** separates a registered peer from an entry created by a cert/service/offline mark — `GetPeerRecord` gates on it, and `mTLSGuard` / relay / `cluster_handlers` rely on that (map presence is NOT registration). **`AddPeer` → `(updated bool, evicted []string)`**; equal-seq merge preserves `Addresses[0]`.
* `invite.go` — **`Check`** (peek) / **`Consume`** / **`CheckAndConsume`**; `HandleClusterJoin` consumes only after successful `SignCSR`.
* `catalog_kinds.go` — **`catalogKinds`** (complete gossip-domain SSOT: `Kind` + `entityFrom` + `current` + `syncOnJoin` + `deliver`) / `syncCatalogToPeer` / `deliverNotification`, **`lookupCachedServiceSchema`**, **`resolveServiceBidTarget`**.
* `outbox.go` — **`notifyWithOutbox`** stages before send and routes eager/retry delivery through `catalogKindFor`; entity extraction/reconciliation have no kind `switch`.
* `unix_listener.go` — thin accept loop; dispatch via **`unixHandlers`** in `unix_handlers.go` (keys from `uischema.MustUnixAction`).
* `unix_handlers.go` — SSOT daemon handler table; `RegisteredUnixActions` for consistency tests; **`requireUnixArgs`** for required-arg guards (does **not** delegate to `uischema.ValidateActionArgs`: arg names diverge after `NormalizeActionArgs`).
* `service_catalog.go` — **`LocalServiceDetail`**, Load/Add/Remove, **`applyServiceAction`**, **`NotifyService*`**, Discover.
* `service_exec.go` — Run/Stream, wait/ingest outputs (`ResultLocalPath` / `OutputHashFromOutputs`); **`submitTrackedTask`**.
* `local_pipelines.go` — **`applyPipelineAction`** / `NotifySchema*`; **`ValidatePipelineSchema`** thin wrapper → `protocol.ValidatePipelineSchema` / `PipelineHasCycle`.
* `vfs_sync.go` — `LocalVFSUpload` / `LocalVFSSubscribe` / `LocalLogs` / `fetchBlobFromPeer` / `announceAndSync`; download fallback skips source peer; **`storage.ErrBlobDiscarded`** is not logged as fail/success.
* `peer_rpc.go` — **`callPeer` / `errPeerSkipped` / `forEachPeer` / `mapEachPeer` / `firstPeer`** + **`gossipToPeer` / `gossipAll`** + `PeerRPC*` (+ `PeerRPCProbe` / `PeerRPCSTUN`); `PeerRPCQUICWait` = `protocol.HolePunchWait`; other timeouts alias `protocol.RPCTimeout*`; `callPeer` keeps peer online on `ErrBlobDiscarded`, skips liveness on `errPeerSkipped`.
* Invites/rotate: CA-key gated mint; join `CheckAndConsume`; rotate acks before local reload; gossip cannot elevate `IsSponsor`.
* VFS `Snapshot() (map, error)` — GC aborts on corrupt index; stage fail-closed on missing local paths.
* `nat.go` — NAT/UPnP; `determineSponsorAndNATStatus` orchestrates `openUDPEndpoint` / `mapPortsWithUPnP` / `startDirectQUIC` / `detectPublicReachability` / `applySponsorStatus`; **`advertisedTCPPort`** / `configTCPPort` / **`refreshPublicUDPFromMapping`** (OnMapped); `IsSponsorOverride` sets flag only (does not skip QUIC).
* `handlers.go` — **`httpRoutes`** table (method, path, handler, `authMode`, `RelayAnon`); `MountHandlers` just iterates it (paths via **`protocol.Path*`**). **`routeIndex`** memoizes the policy with `sync.Once` (lazy, not in `New`) — never rebuild the table per request; cache policy only, never handlers. Subtree paths (`/download/`) must keep the default policy: exact-match lookup cannot apply a laxer one.
* `mtls.go` — `mTLSGuard` consults **`routeAuth(path)`** (unknown path ⇒ `authMTLS`, never fail-open) + **`peerCNFromRequest`**.
* `peer_handlers.go`, `cluster_handlers.go`, `stream_handlers.go` — HTTP by domain (`handlePeerIDAction`, `requirePeerCNMatchesBodyID`, schema notify re-validates); **`HandleAddPeer`** requires mTLS CN (owner vs gossip seq clamp).
* `compute_bridge.go` — bidding via **`BuildServiceBid`** + **`selectBestServiceBid`** / **`DispatchTask`** / **`submitTrackedTask`**.
* `relay.go` — body cap via **`rejectOversizedRelay`** / `relayCapMessage` (derived from `protocol.MaxRelayBodyBytes`); anonymous forwarding via **`relayAllowsAnonymous(path)`**, not a hardcoded path compare; **`OriginPeerID`** preserved into processRelayRequest TLS mock.
* `tls_rotation.go` / `cluster_handlers.go` — rotation payload is **`protocol.RotateTLSPayload`** (no `map[string]string`; the private key never travels).

## Key Workflows

### Pairing
1. `LocalInviteGenerate` / `proxyma invite` → smart token (**CA key required**).
2. Join CSR → `/cluster/join` with **`CheckAndConsume`**.
2. Join: CSR → `/cluster/join` (direct or `ForwardRelay`).
3. mTLS via signed cert; `mTLSGuard` on inter-node HTTP.

### VFS sync
1. Unix/`announceAndSync` → manifests via peers (`forEachPeer` + liveness).
2. Missing blobs → `downloadQueue` → `fetchBlobFromPeer` → `StoreRemoteBlob`.

### Compute
1. `RequestServiceToCluster` bids via `mapEachPeer` (+ local).
2. `DispatchTask` stages with `StageAndRewrite`, then `SubmitTask`.
3. Handlers from `BuildHandler`; detail via `LocalServiceDetail`.

## Test and linter

The testing contract and Docker case matrix live in [`tests/e2e/README.md`](tests/e2e/README.md). Keep that file, this section, [`.agents/AGENTS.md`](.agents/AGENTS.md), and the two testing skills synchronized when test entry points, helpers, profiles, or decision gates change.

Use the layer that owns the behavior:

* `make test` — Go unit/package tests, including the real CLI/daemon golden path in `cmd/proxyma/cli_daemon_test.go`.
* `make test-integration` — live public-contract tests: a real bind daemon subprocess over Unix IPC plus a real mTLS server restart. Bind coverage includes service/storage actions; Android-facing parameter/ui-hint/permission metadata; bandwidth/log telemetry; enrolled-peer DTOs; stream/cancel; task polling; complete pipeline add/run/list/get/clone/remove lifecycle; and service/pipeline/VFS/blob persistence across daemon restart.
* `make test-cover` — uncached `go test ./...` coverage plus the package ratchet in `cmd/coverage-ratchet`.
* `make test-e2e-harness` — profile-validator fixtures, repository profile invariants, and V1/V2 invite/secret diagnostic redaction.
* `make test-sanitizer` — compatibility alias for `test-e2e-harness`.
* `make test-race` — the complete `go test -race ./...` suite.
* `make test-ci` — local non-Docker gates: `test-cover`, `test-e2e-harness`, and `test-race`.
* `make test-android-contract` — `androidcontract` host-tag contracts: immediate WebRTC registration rejection and exact signaling JSON HTTP 501.
* `make test-android` — host contracts plus one fresh AAR, expanded `javap` API checks, Kotlin unit tests, lint, and assemble.
* `make coverage` — stable E2E `full` plus separate unit, E2E, and source-block-union coverage reports.
* `make test-e2e-pr` — deterministic Docker public contracts.
* `make test-e2e-network` — Docker topology and fault injection.
* `make test-e2e` / `make test-e2e-full` — stable Docker suite.
* `E2E_CASE=NN ./tests/e2e/run.sh` — one case; `E2E_PROFILE=<name>` selects `functional`, `pr`, `network`, `infrastructure`, `smoke`, `quarantine`, `full`, or explicit `all`. With no selector the runner defaults to stable `full`.

Coverage semantics:

* `scripts/coverage.sh` requires E2E directories containing both `covmeta.*` and `covcounters.*`; absence fails by default. `COVERAGE_ALLOW_MISSING_E2E=true` is an explicit local unit-only escape, not a green E2E claim.
* `coverage-unit.out` comes from all `go test ./...` packages. `coverage-e2e.out` comes from the instrumented `./cmd/proxyma` Docker executable and linked instrumented code; it does not measure bind-only or otherwise unreachable code. `coverage.out` is their block union, not an average.
* `internal/covermerge` emits one record per source range: duplicate `set` blocks are ORed and `count`/`atomic` counts are summed after mode/statement validation. `scripts/merge_profiles.go --strict` requires both report files.
* `go run ./cmd/coverage-ratchet check scripts/coverage_baseline.json coverage-unit.out` enforces package floors; regressions and missing tracked packages fail, while untracked packages warn. `update` rewrites one-decimal floors while preserving exclusions; epsilon is `0.1`.
* New bind/CLI/Android contracts change measured coverage. The parent coverage work must regenerate `coverage-unit.out` and run ratchet `update` before any new package floor or aggregate total is documented. Until then, freeze no numeric totals; ratchet behavior is the contract.

New or modified asynchronous tests must not use fixed sleeps. In Go, synchronize with channels/contexts and keep deadline timeouts only as failure bounds. In E2E, use `wait_until` / `wait_for_output` and assert the resulting public CLI or mTLS API contract. Docker/container state is allowed for Given/setup, fault injection, infrastructure checks, and sanitized diagnostics, never as the Then for a product behavior.

There are 27 executable E2E cases: 26 stable in `full`, case 13 in `quarantine`, and number 23 intentionally absent until a public bidi API supports multiple client messages and end-to-end cancellation. `functional`/`pr` include 26–28; `network` includes 25. Case 01 verifies the OCR PDF public download against its manifest SHA-256, non-empty size, and `%PDF-` magic. Case 25 covers peer OFFLINE/ONLINE recovery, 26 peer VFS/blob restart persistence, 27 unsubscribe/purge/resubscribe/open, and 28 durable service removal across restart.

Every E2E case must be added explicitly to the appropriate profile files; never rely on filename discovery as a stable green gate. All cases use `set -euo pipefail`, a unique static `E2E_PROJECT_NAME`, shared `install_e2e_case_trap`, and cleanup before setup. `scripts/validate_e2e_profiles.sh` rejects non-executable/duplicate/orphan/overlapping/ambiguous entries and `pr`/`functional` drift. Case 05 is infrastructure-only and case 14 is fake-frame smoke.

Do not use the suite to mark blocked objectives green: ambiguous dynamic-port validation, passive sync without an SLO, real UPnP/NAT-PMP, deterministic OTel-driven balancing, real low-latency screen capture/input, `uv`/RGBA, editor/UI/Android behavior, or literal mTLS on intentional anonymous bootstrap routes.

After finishing an implementation, run `make lint`, `make test-cover`, `make test-e2e-harness`, and `make test-integration`, then the narrowest relevant E2E profile/case. Run `make test-android-contract` for Android-tag boundaries. For changes affecting broad concurrency/lifetimes, run `make test-race`; for E2E-facing changes, finish with `make test-e2e-full`. `make test-ci` combines the local coverage, harness, and race gates. Fix failures and re-run the affected gates.

`make test-race` runs the complete `go test -race ./...` suite. H1 (`ReloadTLSConfig` mutating live TLS state) and H2 (NAT mapper work after shutdown) are closed; the full race suite is required even though it remains a separate, slower target.

CI intentionally has two complete Go passes in its main job: coverage/ratchet, then race. Pull requests run E2E `pr` plus `network`; pushes run `full`; the weekly schedule runs instrumented `full` and publishes unit/E2E/union coverage. Manual dispatch selects profile and coverage mode.

Environment gotchas (do not misread these as flaky tests):

* The WebRTC and CA-rotation tests need **real UDP sockets**. Inside a network-restricted sandbox they fail deterministically; run them with full permissions.
* Don't pipe suite output through `tail`/`head` when triaging a failure: both the Go test output and the E2E runner name the failing case *above* the summary block.
* E2E logs and failure artifacts must pass through `tests/e2e/lib/dump.sh`; do not upload raw credentials, invite tokens, or private keys. V1/V2 invite detection redacts only a valid complete token line; JSON `token`/`secret` values are redacted, while hashes, generic base64, and embedded lookalikes remain diagnostic data.
