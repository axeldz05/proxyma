# Proxyma - Agent Context & Reference Guide

Condensed context for AI agents: architecture, SSOT helpers, what not to reinvent, and coding rules.

---

## Project Goal

**Proxyma** is a distributed, heterogeneous P2P resource and compute orchestrator (Go). It unifies devices (servers, desktops, mobiles) into one mesh that shares compute, storage, and related capabilities over mTLS (with QUIC hole-punch and HTTP relay fallback).

## Design Rules (Always On)

* **Golden rule (duplication)**: If changing one behavior requires touching **>2 code zones**, compress into a shared helper (see semantic-compression skill). Do **not** copy service CRUD, peer fan-out, relay forward, blob fetch/stage, or unix dial stacks.
* **Continuous granularity (3 tiers)**: L3 wrappers must not hide L1/L2. Example: `dispatchUnixOrLocal` / `dispatchUnixLocalOrOffline` (L3) use `sendUnixSocketCommand` which uses `DialUnix` / `WriteUnixRequest` / `ReadUnixResponse` (L1). Streaming uses `ScanUnixNDJSON` — never fork a full dial path.
* **Slice boundary guards** when trimming slices.
* **Domain enums in `protocol`**: `ServiceType`, `IsStreaming()`, `Normalize()` all read `serviceTypeSpecs` (`protocol/service_types.go`). No ad-hoc type string switches anywhere — a new type is 1 row there + 1 row in `compute.serviceTypeBuilders`.
* **Tables over switches**: a discriminant that already has an SSOT table must not grow a parallel `switch` — gossip kind (`server.catalogKinds`), HTTP route + auth policy (`server.httpRoutes`), service type (above).
* **Node addresses**: `protocol.HTTPSAddr` / `HTTPSAddrPort` (IPv6-safe). Never `fmt.Sprintf("https://%s:%s", ...)`.
* **No `panic` / `os.Exit` outside `main` and `Execute`**: CLI commands use `RunE`; libraries return errors. Bolt/disk failures propagate instead of collapsing into a bool.
* **UI hints**: `protocol.InferUIHint` / `EffectiveUIHint` write/fill at schema time; bind passes through; Android **never** re-sniffs param names.
* **Bind errors**: `BindErrorJSON` / `BindMessageJSON` / `ParseBindError` / `IsBindError` — JSON `{"error":...}` only (no `"error:"` prefix; never double-wrap).
* **In-memory registry**: Persist `services.json` only on mutation (`compute.UpsertLocalService` / `DeleteLocalService`); runtime resolves via `Compute.GetService` / `GetHandler`.
* **JSON contracts**: One SSOT — e.g. `protocol.BandwidthStats` tags (`upload_speed`, …). CLI must not redefine parallel structs with different tags.
* **No unrequested commits**.

## Repository Map (Current)

### CLI — `cmd/proxyma/`
* `root.go` — Cobra from `uischema.VisibleRegistry("cli")` + `Execute`.
* `cli_actions.go` — `executeActionLocal` → **`NormalizeActionArgs`** → **`ValidateActionArgs`** → `cliEscapes` OR **`InvokeDomainActionPrepared`** (open/join/run/clone/edit escapes).
* Byte/rate rendering: call `uischema.FormatBytes` / `FormatRate` directly (the local wrapper file is gone).
* `cli_open.go` — editor launch, stream listener, system open.
* `service_help.go` — schema help; `ParseInputsToJSON` → `uischema.NormalizePayloadJSON`; offline schema via `GetServiceSchema` offline arm.
* Table render: `uischema.ProjectRows` in `root.go`.

### Bindings — `cmd/proxyma-bind/` (gomobile + CLI bridge)
* **IPC L1**: `DialUnix`, `WriteUnixRequest`, `ReadUnixResponse`, `ScanUnixNDJSON` in `bind.go`.
* **IPC L2/L3**: `sendUnixSocketCommand`, **`InvokeDomainAction`** (L3 Normalize→Validate) / **`InvokeDomainActionPrepared`** (L2) / `NormalizeActionArgs` / **`ValidateActionArgs`** / **`uischema.NormalizePayloadJSON`**, `dispatchUnixOrLocal`, `dispatchUnixLocalOrOffline` + **`offlineHooks`** map (add/remove/detail). CLI prep once then Prepared; wrappers/JNI use L3.
* Execution: **`server.CallUnixUnary`** — single body shared with unix listener.
* `BindErrorJSON` / `BindMessageJSON` / `ParseBindError` / `IsBindError` — error envelope SSOT.
* Socket path: **`protocol.UnixSockPath`** (never hardcode `proxyma.sock`).
* `ParameterDetail` = `uischema.ParameterDetail`.
* `GetServiceSchema` / `GetServiceDetails`; `RunPipeline` → `RunService` alias.
* Do **not** reimplement offline `services.json` RMW by hand.

### Server — `internal/server/`
* `server.go` — lifecycle (`New`/`ListenAndServe`/`Shutdown`), bandwidth wrappers.
* `peers.go` — topology (`AddPeer`/`AnnouncePresence`/`RemovePeer`/`SetPeer*`/`CheckNAT`).
* `catalog_kinds.go` — **`catalogKinds`** (SSOT of a gossip domain: `Kind` + `syncOnJoin` + `deliver`) / `syncCatalogToPeer` / `deliverNotification`, **`lookupCachedServiceSchema`**, **`resolveServiceBidTarget`**.
* `outbox.go` — **`notifyWithOutbox`** (L2: send → log → `enqueueOutbox`); `deliverOutboxEntry` looks up `catalogKindFor`, no `switch`.
* `unix_listener.go` — thin accept loop; dispatch via **`unixHandlers`** in `unix_handlers.go` (keys from `uischema.MustUnixAction`).
* `unix_handlers.go` — SSOT daemon handler table; `RegisteredUnixActions` for consistency tests; **`requireUnixArgs`** for required-arg guards (does **not** delegate to `uischema.ValidateActionArgs`: arg names diverge after `NormalizeActionArgs`).
* `service_catalog.go` — **`LocalServiceDetail`**, Load/Add/Remove, **`applyServiceAction`**, **`NotifyService*`**, Discover.
* `service_exec.go` — Run/Stream, wait/ingest outputs (`ResultLocalPath` / `OutputHashFromOutputs`); **`submitTrackedTask`**.
* `local_pipelines.go` — **`applyPipelineAction`** / `NotifySchema*`; **`ValidatePipelineSchema`** thin wrapper → `protocol.ValidatePipelineSchema` / `PipelineHasCycle`.
* `vfs_sync.go` — `LocalVFSUpload` / `LocalVFSSubscribe` / `LocalLogs` / `fetchBlobFromPeer` / `announceAndSync`.
* `peer_rpc.go` — **`callPeer` / `forEachPeer` / `mapEachPeer` / `firstPeer`** + **`gossipToPeer` / `gossipAll`** + `PeerRPC*` (+ `PeerRPCProbe` / `PeerRPCSTUN`); `PeerRPCQUICWait` = `protocol.HolePunchWait`; other timeouts alias `protocol.RPCTimeout*`.
* `nat.go` — NAT/UPnP; `determineSponsorAndNATStatus` orchestrates `openUDPEndpoint` / `mapPortsWithUPnP` / `startDirectQUIC` / `detectPublicReachability` / `applySponsorStatus`; **`advertisedTCPPort`** / `configTCPPort` / **`refreshPublicUDPFromMapping`** (OnMapped); `IsSponsorOverride` sets flag only (does not skip QUIC).
* `handlers.go` — **`httpRoutes`** table (method, path, handler, `authMode`, `RelayAnon`); `MountHandlers` just iterates it (paths via **`protocol.Path*`**).
* `mtls.go` — `mTLSGuard` consults **`routeAuth(path)`** (unknown path ⇒ `authMTLS`, never fail-open) + **`peerCNFromRequest`**.
* `peer_handlers.go`, `cluster_handlers.go`, `stream_handlers.go` — HTTP by domain (`handlePeerIDAction`, `requirePeerCNMatchesBodyID`, schema notify re-validates).
* `compute_bridge.go` — bidding via **`BuildServiceBid`** + **`selectBestServiceBid`** / **`DispatchTask`** / **`submitTrackedTask`**.
* `relay.go` — body cap via **`rejectOversizedRelay`** / `relayCapMessage` (derived from `protocol.MaxRelayBodyBytes`); anonymous forwarding via **`relayAllowsAnonymous(path)`**, not a hardcoded path compare; **`OriginPeerID`** preserved into processRelayRequest TLS mock.
* `tls_rotation.go` / `cluster_handlers.go` — rotation payload is **`protocol.RotateTLSPayload`** (no `map[string]string`; the private key never travels).

### Test harness — `internal/testutil/`
* `cluster.go` — **`NewStorageEngine(cfg)`** (temp dir + noop callbacks), **`InitClusterCA`** (L1) / **`IssueNode`** → `NodeTLS` (L2) / **`NewNodeTLS`** (L3, dir + CA + cert + `tls.Config`).
* Tests whose subject *is* a TLS/storage step (CSR contents, corrupt PEM, download callback) keep calling the `p2p` / `storage` L1 directly — the harness must not hide them.
* Safe to import `storage` / `p2p`: every test package is an external `*_test`.

### Bindings — `cmd/proxyma-bind/`
* IPC L1–L3 + **`dispatchUnixStreamOrLocal`**; `BindErrorJSON` on `StartNode`/`ChangeStorageLocation`.
* `LookupServiceSchema` → `resolveServiceSchema`; `GetServiceDetails` via `DescribeParameter`; `ResolveLocalBlob`; **`ResolveTaskResultPath`**.

### Android — `cmd/proxyma-android/`
* Tree may lack `.kt` sources; when UI returns, treat Compose as **Registry interpreter**:
  - L1: `VisibleRegistry(surface)` + `ProjectRows` / `FormatBytes`
  - L2 gomobile: **`InvokeDomainAction(domain, action, args)`** (typed wrappers optional L3, not a second truth)
  - Forms from `Parameters`; tables from `Columns` + `ProjectRows` — **no** hardcoded `domain.action` UI switches
* Trust bind `uiHint`; `getResultPath` → bind `ResolveTaskResultPath`.

## Key Workflows

### Pairing
1. `LocalInviteGenerate` / `proxyma invite` → smart token.
2. Join: CSR → `/cluster/join` (direct or `ForwardRelay`).
3. mTLS via signed cert; `mTLSGuard` on inter-node HTTP.

### VFS sync
1. Unix/`announceAndSync` → manifests via peers (`forEachPeer` + liveness).
2. Missing blobs → `downloadQueue` → `fetchBlobFromPeer` → `StoreRemoteBlob`.

### Compute
1. `RequestServiceToCluster` bids via `mapEachPeer` (+ local).
2. `DispatchTask` stages with `StageAndRewrite`, then `SubmitTask`.
3. Handlers from `BuildHandler`; detail via `LocalServiceDetail`.
