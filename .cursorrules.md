# Proxyma - Agent Context & Reference Guide

Condensed context for AI agents: architecture, SSOT helpers, what not to reinvent, and coding rules.

---

## Project Goal

**Proxyma** is a distributed, heterogeneous P2P resource and compute orchestrator (Go). It unifies devices (servers, desktops, mobiles) into one mesh that shares compute, storage, and related capabilities over mTLS (with QUIC hole-punch and HTTP relay fallback).

## Design Rules (Always On)

* **Golden rule (duplication)**: If changing one behavior requires touching **>2 code zones**, compress into a shared helper (see semantic-compression skill). Do **not** copy service CRUD, peer fan-out, relay forward, blob fetch/stage, or unix dial stacks.
* **Continuous granularity (3 tiers)**: L3 wrappers must not hide L1/L2. Example: `dispatchUnixOrLocal` (L3) uses `sendUnixSocketCommand` which uses `DialUnix` / `WriteUnixRequest` / `ReadUnixResponse` (L1). Streaming uses `ScanUnixNDJSON` — never fork a full dial path.
* **Slice boundary guards** when trimming slices.
* **Domain enums in `protocol`**: `ServiceType`, `IsStreaming()`, `Normalize()`. No ad-hoc type string switches in bind/Android for streaming detection.
* **UI hints in schema**: `ServiceParameter.UIHint` (`file_picker` / `image_picker`). Android/CLI consume flags; do not re-sniff param names across Go+Kotlin.
* **In-memory registry**: Persist `services.json` only on mutation (`compute.UpsertLocalService` / `DeleteLocalService`); runtime resolves via `Compute.GetService` / `GetHandler`.
* **JSON contracts**: One SSOT — e.g. `protocol.BandwidthStats` tags (`upload_speed`, …). CLI must not redefine parallel structs with different tags.
* **No unrequested commits**.

## Repository Map (Current)

### CLI — `cmd/proxyma/`
* `root.go` — Cobra + uischema registry; uses `resolveServiceName` / `resolvePayloadRaw`; streaming decision via `GetServiceSchemaLocal` → raw `protocol.ServiceSchema`.
* `service_help.go` — schema help; `sampleValue` shared by KV/JSON sample builders; offline schema fallback via `compute.LoadServicesMap`.
* `helpers.go`, `run.go`, `init.go` — config/logger/daemon.

### Bindings — `cmd/proxyma-bind/` (gomobile + CLI bridge)
* **IPC L1**: `DialUnix`, `WriteUnixRequest`, `ReadUnixResponse`, `ScanUnixNDJSON` in `bind.go`.
* **IPC L2/L3**: `sendUnixSocketCommand`, `dispatchUnixOrLocal` — **prefer these** for unary APIs (peers, telemetry, storage, pipelines).
* `GetServiceSchema(name)` — raw schema JSON (CLI / domain). `GetServiceDetails(name)` — Android L3 DTO (`ServiceDetail` + `uiHint`).
* `service.go` — Add/Remove use `compute.BuildLocalServiceFromArgs` offline; online via `LocalServiceAdd` / unix.
* Do **not** reimplement offline `services.json` RMW by hand.

### Server — `internal/server/`
* `server.go` — lifecycle, TLS HTTP, construction hooks (`SetVFSBlobResolver` / `SetVFSBlobStager` → `fetchBlobFromPeer` / `StageLocalFile`).
* `unix_listener.go` — local unix IPC dispatcher.
* `local_services.go` — load/run/stream/add/remove services.
* `local_pipelines.go` — pipeline CRUD/validate/notify.
* `local_api.go` — invite, bandwidth, peers list (thin).
* `peer_rpc.go` — **`callPeer` / `forEachPeer`** + named timeouts (`PeerRPCShort`, `PeerRPCDefault`, `PeerRPCBlob`, …). Use for peer fan-out + liveness.
* `vfs_sync.go` — sync, `downloadWorker`, `fetchBlobFromPeer`, `notifyPeers`.
* `compute_bridge.go` — bidding, `DispatchTask`, QUIC ensure.
* `handlers.go` — mTLS HTTP; invite HTTP delegates to `LocalInviteGenerate`.
* `relay.go`, `nat.go`, `bandwidth.go`, `tls_rotation.go`, `registry.go`, `invite.go`.

### P2P — `internal/p2p/`
* `PeerClient` interface includes routing lifecycle: `UpdatePeerRoute`, `RemovePeerRoute`, `SetNodeID`, `SetOwnAddress`, `UpdateSponsorAddress`, `CloseIdleConnections`, `SetQUICManager` — **no ad-hoc type assertions**.
* `ForwardRelay` — single path for `/relay/forward` (router + join).
* `FirstQUICAddr`, `VerifyPeerCN` — shared helpers.
* `tls.go` — CA/CSR/`LoadNodeTLS` (already centralized).
* `router.go`, `holepunch.go`, `join.go`, `helpers.go` (`doJSON` / `sendRequest`).

### Storage — `internal/storage/`
* `StageLocalFile(path)` — L2 open→CAS→Upsert+subscribe. Keep `SavePhysicalBlob` / `Upsert` public (L1).
* `GetBlobPath` / `GetLocalBlobPath` (alias). Prefer `StoreRemoteBlob` when `IndexEntry` exists.

### Compute — `internal/compute/`
* `services_config.go` — **SSOT for services.json**: `LoadServicesMap`, `SaveServicesMap`, `BuildLocalServiceFromArgs`, `UpsertLocalService`, `DeleteLocalService`, `BuildHandler(type, exec)`.
* `handlerBuilder.go` — script/gRPC/bidi builders; `BuildGRPCBidiStreamHandler` aliases `BuildGRPCBidiHandler`.
* `compute.go` / `registry.go` — task pool + in-memory service registry.

### Protocol — `internal/protocol/`
* Pure types: `LocalService`, `ServiceSchema`, `ServiceParameter` (+ `ui_hint`), `ServiceType.Normalize()` / `IsStreaming()`, `BandwidthStats`, `UnixRequest`/`UnixResponse`, `VFSFileStatus` (no duplicate `CLIFileEntry`).

### Android — `cmd/proxyma-android/`
* Consume `uiHint` / `isStreaming` from bind JSON. Avoid name-heuristic duplication for file/image pickers when schema provides hints.

## What Already Exists (Do Not Reinvent)

| Need | Use |
|------|-----|
| services.json I/O + parse args | `compute.Load/Save/Build/Upsert/Delete*` |
| Register handler from type | `compute.BuildHandler` |
| Fan-out RPC + online/offline | `server.callPeer` / `forEachPeer` |
| Download blob + store | `server.fetchBlobFromPeer` |
| Stage local path into VFS | `storage.StageLocalFile` |
| Relay POST forward | `p2p.ForwardRelay` |
| Unix unary/stream IPC | bind `DialUnix`… + `dispatchUnixOrLocal` / `ScanUnixNDJSON` |
| Raw vs Android service meta | `GetServiceSchema` vs `GetServiceDetails` |
| HTTP JSON responses | `utils.RespondJSON` / `DecodeJSONOrError` |
| TLS configs | `p2p.LoadNodeTLS` |

## Key Workflows

### Pairing
1. `LocalInviteGenerate` / `proxyma invite` → smart token.
2. Join: CSR → `/cluster/join` (direct or `ForwardRelay`).
3. mTLS via signed cert; `mTLSGuard` on inter-node HTTP.

### VFS sync
1. Unix/`ExecuteSync` → manifests via peers (`forEachPeer` + liveness).
2. Missing blobs → `downloadQueue` → `fetchBlobFromPeer` → `StoreRemoteBlob`.

### Compute
1. `RequestServiceToCluster` bids (local + peers).
2. `DispatchTask` stages local paths with `StageLocalFile`, then `SubmitTask`.
3. Handlers from `BuildHandler` / registry; stream via `ExecuteStream` / unix `service_stream`.
